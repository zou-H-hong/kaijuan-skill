# 开卷 KaiJuan · AI 辅助深度阅读 Skill

一个面向 [Claude Code](https://docs.anthropic.com/en/docs/claude-code/skills) / CodePilot 等 Agent 的 Skill，把 AI 变成你的阅读伙伴：从建库初始化到阅读中的知识沉淀，一站式管理你的读书工作流。

> 设计思路借鉴了 NotebookLM 的「围绕资料对话」方式，在此之上加入了个人阅读习惯的调整——不止于问答，更多围绕书中内容展开互动：金句解读、观点延伸、人物与概念的沉淀，让一本书越读越厚。

## 功能

**📖 初始化工作流**（触发词：「开卷skill」，仅此一词，避免误触发）

1. 询问书名（新书 / 继续旧书）
2. 自动建立书籍文件夹与笔记结构（重名自动区分）
3. 检查书源（向量库 / 原文 / 笔记，均可降级）
4. 搜索豆瓣确认版本，提取书籍元信息
5. 生成作者背景与写书背景（同作者自动复用）
6. 基于书源生成学习指南：10 道简答题 + 答案、5 道论述题、术语表
7. 完成确认，进入阅读模式

**🧠 阅读中的知识网络**

- **主动引导**：回答问题的同时延伸背景、对比观点、推荐延伸阅读
- **名人堂**：重要人物自动建档，跨书关联
- **知识卡片**：重要概念与金句沉淀为可复用卡片，互相关联

## 目录结构

初始化后你的笔记库将呈现：

```
笔记库根目录/
├── .claude/skills/kaijuan/SKILL.md   # 本 skill
├── 读书/
│   └── 书名/
│       ├── 章节笔记/
│       ├── 作者背景.md
│       ├── 学习指南.md
│       └── vectordb/                 # 可选
├── 名人堂/
│   └── 人物名.md
└── 知识卡片/
    └── 概念名.md
```

## 安装

将整个 `kaijuan-skill` 目录复制到你的笔记库（或项目）的 skills 目录：

```bash
# Claude Code 项目级
cp -r kaijuan-skill /path/to/your-vault/.claude/skills/kaijuan

# 或用户级（所有项目可用）
cp -r kaijuan-skill ~/.claude/skills/kaijuan
```

在笔记库根目录启动对话，说「**开卷**」即可开始。

## 前置依赖

| 依赖 | 必需性 | 说明 |
|------|--------|------|
| Markdown 笔记库 | 必需 | Obsidian 或任意 md 目录均可 |
| 网络搜索工具 | 推荐 | 用于检索豆瓣书籍信息；不可用时由用户手动提供 |
| 书籍书源 | 可选 | 向量库 / 原文 / 笔记任一即可；没有则跳过学习指南生成 |

## 自定义

SKILL.md 开头的「路径配置」表定义了三个默认目录（`读书/`、`名人堂/`、`知识卡片/`），可按你的笔记库结构调整。
