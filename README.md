# 开卷 KaiJuan · AI 辅助深度阅读 Skill

一个面向 [Claude Code](https://docs.anthropic.com/en/docs/claude-code/skills) / CodePilot 等 Agent 的 Skill，把 AI 变成你的阅读伙伴：从建库初始化到阅读中的知识沉淀，一站式管理你的读书工作流。

> 设计思路借鉴了 NotebookLM 的「围绕资料对话」方式，在此之上加入了个人阅读习惯的调整——不止于问答，更多围绕书中内容展开互动：金句解读、观点延伸、人物与概念的沉淀，让一本书越读越厚。

## 功能

**📖 初始化工作流**（触发词：「开卷skill」，仅此一词，避免误触发）

1. 询问书名（新书 / 继续旧书）
2. 自动建立书籍文件夹与笔记结构（重名自动区分）
3. 检查书源（向量库 / 原文 / 笔记，均可降级）
4. 搜索豆瓣确认版本，提取书籍元信息
5. 生成作者背景与写书背景（同作者自动复用）
6. 基于书源生成学习指南：10 道简答题 + 答案、5 道论述题、术语表
7. 生成「相关概念」索引页：链接到认知卡片，读书时悬停速览
8. 完成确认，进入阅读模式

**🧠 阅读中的知识网络**

- **主动引导**：回答问题的同时延伸背景、对比观点、推荐延伸阅读
- **名人堂**：重要人物自动建档，跨书关联
- **认知卡片**：重要概念与金句沉淀为可复用卡片，集中存放、跨书互链
- **相关概念索引**：每本书一页，wiki 链接指向卡片（不重复存放），悬停即读

## 目录结构

初始化后你的笔记库将呈现：

```
笔记库根目录/
├── .claude/skills/kaijuan/SKILL.md   # 本 skill
├── 读书/
│   ├── 认知卡片/                     # 概念卡片池（跨书共享）
│   │   └── 概念名.md
│   └── 书名/
│       ├── 章节笔记/
│       ├── 作者背景.md
│       ├── 学习指南.md
│       ├── 相关概念.md               # 本书概念索引（链接到卡片池）
│       └── vectordb/                 # 可选
└── 名人堂/
    └── 人物名.md
```

## 安装

**方式一：npx（推荐）**

```bash
npx skills add https://github.com/zou-H-hong/kaijuan-skill --skill kaijuan
```

**方式二：让 AI Agent 帮你装**

把这段话直接发给有 shell 权限的 AI Agent:

```
帮我安装 kaijuan skill。请把 https://github.com/zou-H-hong/kaijuan-skill
克隆到 ~/.claude/skills/kaijuan,安装完成后检查 SKILL.md 是否存在。
```

已经安装过的话，用这段话更新：

```
帮我更新 kaijuan skill:进入 ~/.claude/skills/kaijuan,执行 git pull。
```

**方式三：手动**

```bash
git clone https://github.com/zou-H-hong/kaijuan-skill ~/.claude/skills/kaijuan
```

## 使用

安装后直接对 Agent 说：

```
开卷skill
```

Agent 会依次引导你：输入书名 → 确认豆瓣版本 → 建立笔记结构 → 检查书源 → 生成作者背景、学习指南与相关概念索引，然后进入阅读模式。

## 前置依赖

| 依赖 | 必需性 | 说明 |
|------|--------|------|
| Markdown 笔记库 | 必需 | Obsidian 或任意 md 目录均可 |
| 网络搜索工具 | 推荐 | 用于检索豆瓣书籍信息；不可用时由用户手动提供 |
| 书籍书源 | 可选 | 向量库 / 原文 / 笔记任一即可；没有则跳过学习指南生成 |

## 自定义

SKILL.md 开头的「路径配置」表定义了三个默认目录（`读书/`、`名人堂/`、`读书/认知卡片/`），可按你的笔记库结构调整。
